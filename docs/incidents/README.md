# Incident archive

Every Sev1 / Sev2 incident gets a write-up here within 48 hours.
The template lives in [`../INCIDENT.md`](../INCIDENT.md) §9.

## Convention

- Filename: `YYYY-MM-DD-<short-slug>.md`
- One incident = one file.
- File is committed to main as part of the post-incident PR.
- Sensitive info (user emails, payment IDs) → redact to
  `<user-id-redacted>` style placeholders.
